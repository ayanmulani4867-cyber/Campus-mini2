ℹ️ About Campus Connect Project

Mini Project Phase 2 (50%)

Campus Connect is a comprehensive college management frontend portal built using pure HTML5, CSS3, and Vanilla JavaScript. It provides multi-role functionality for Students, Faculty, and Administrators with responsive design, instant client-side state handling, interactive roll-call attendance, and dynamic dashboards.
