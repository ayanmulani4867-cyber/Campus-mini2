# Campus Connect Production Deployment Guide

This guide covers production deployment on **Render** as a single unified **Python Web Service** with PostgreSQL.

---

## 1. Render Deployment via Blueprint (Recommended)

Campus Connect includes an infrastructure-as-code blueprint in `render.yaml`.

### Step 1: Connect GitHub Repository
1. Push your repository to GitHub:
   ```bash
   git add .
   git commit -m "Production-ready single Flask + PostgreSQL service"
   git push origin main
   ```
2. In the Render Dashboard, click **New +** and select **Blueprint**.
3. Select your repository.

### Step 2: Automatic Resource Creation
Render will automatically provision:
1. **Web Service (`campus-connect`)**:
   - Runtime: `Python`
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `flask db upgrade && gunicorn --bind 0.0.0.0:$PORT --workers 2 --timeout 120 app:app`
   - Environment: `PYTHON_VERSION=3.11.0`, `FLASK_ENV=production`
2. **Managed PostgreSQL Database (`campus-connect-db`)**:
   - Securely wired to `DATABASE_URL`

### Step 3: Seed Initial ERP Accounts
In the Render Web Service Shell (`campus-connect`):
```bash
python seed.py
```

## 2. Render Manual Service Configuration (Without Blueprint)

If configuring services manually in the Render dashboard:

### Python Web Service
| Setting | Value |
|---|---|
| **Name** | `campus-connect` |
| **Repository** | Your GitHub repository |
| **Branch** | `main` |
| **Runtime** | `Python` |
| **Build Command** | `pip install -r requirements.txt` |
| **Start Command** | `flask db upgrade && gunicorn --bind 0.0.0.0:$PORT --workers 2 --timeout 120 app:app` |
| **Plan** | Free |

**Environment Variables**:
| Variable | Value / Source |
|---|---|
| `DATABASE_URL` | Your PostgreSQL connection string |
| `SECRET_KEY` | A secure random string (generated by Render) |
| `FLASK_ENV` | `production` |
| `PYTHON_VERSION` | `3.11.0` |

## 3. Local Development

```bash
# 1. Clone repository
git clone https://github.com/your-org/campus-connect.git
cd campus-connect

# 2. Create virtual environment
python -m venv .venv
source .venv/bin/activate  # or .venv\Scripts\activate on Windows

# 3. Install dependencies
pip install -r requirements.txt

# 4. Set up environment
cp .env.example .env
# Edit .env with your local PostgreSQL credentials

# 5. Apply migrations
flask db upgrade

# 6. Seed initial accounts
python seed.py

# 7. Start application
python app.py
# Access http://127.0.0.1:5000 in your browser
```

## 4. Production Checklist

- [x] Single unified application (no separate frontend build, no Node.js).
- [x] Pure HTML5 / CSS3 / Vanilla JS directly served by Flask.
- [x] Flask-Migrate database migrations run automatically on build/startup.
- [x] Gunicorn WSGI server handles all web traffic (`app:app` on `$PORT`).
- [x] Passwords securely hashed with `scrypt` via Werkzeug.
- [x] Multi-tab isolated cryptographic sessions and server-side RBAC protection.
